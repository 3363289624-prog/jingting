# 精听

单文件、零构建的英语精听网页，支持本地导入音频与 SRT、逐句循环、字幕跟随、中英切换、倍速及定时暂停。逐词高亮基于句级时间估算；长按英文单词可唤起已安装的欧路词典查词。

在项目目录运行 `python -m http.server 8080`，通过 `http://localhost:8080/` 打开。请使用 HTTP 或 HTTPS；直接打开本地 HTML 时浏览器可能无法持久保存数据。手机也可以访问本仓库启用后的 GitHub Pages 地址。

音频、字幕与译文保存在本机浏览器的 IndexedDB。不同浏览器、设备和网址的数据相互独立。翻译仅在用户主动操作时调用用户自行配置的接口。

`samples/` 提供测试字幕，不含音频。需要自行准备音频。定时暂停在浏览器被系统挂起时可能延迟。`精听-手机网页包.zip` 包含网页、样本和安卓启动说明。
