精听 1.18-test · 精听与复习优化版

本源码仅提供新包名 app.jtpractice.offlineplayer，versionCode 9，versionName 1.18-test。
Java 源码包名仍为 com.jingting.app。网页保持 assets/index.html 单文件；没有 CDN、前端框架或 npm 依赖。

本版新增：
1. 整份字幕校准：目录或材料更多操作进入，0.1 秒步长、范围 ±30 秒。句子切换、跳句、跟读和词时间锚点一起平移；原始字幕、收藏定位键保留。逐词高亮校准仍可单独微调 ±1.5 秒。
2. 收藏连续复习：收藏列表支持顺序/随机播放未掌握句；可标记或取消“已掌握”，状态进入材料备份。上一句/下一句按复习队列移动，手动拖动进度会退出队列。
3. 盲听模式：播放目录中的二级入口。每句默认隐藏，点击揭晓和重听；换句、重新打开材料时重新隐藏。未揭晓句子不生成字幕文字节点。
4. 导入配对确认：批量导入和单独补导字幕均先确认，可手动改配或跳过。同名音频默认跳过，明确选择替换才覆盖。所有文件准备成功后才在同一事务中写入。
5. 刷新率与后台：默认跟随系统，可选请求 120Hz。Android 音频改为平台 MediaPlayer，统一处理原生音频焦点、锁屏媒体会话、前台播放服务及耳机断开。失去焦点后暂停，不自动恢复；关键跟读和复习定时器增加原生 Handler 回调并去重。

数据与播放：
- 更新保留原包名、签名和 WebView 存储来源。不需要数据库迁移；旧材料没有新字段时采用默认值。
- Android 打开材料时，将当前音频分块准备到 App 私有缓存，由原生播放器解码；缓存随切换和关闭清理，启动时清理残留。音频不上传。
- 原生句末边界直接停止解码播放。播放、拖动、暂停等异步事件带操作序号，过期事件不会影响下一遍。
- MediaPlayer 的播放唤醒锁仅用于实际播放；跟读间隙使用有超时的短唤醒锁，暂停与退出时释放。
- SRT 的逐词时间仍是估算；VTT 行内时间锚点可用。没有进行语音识别或强制对齐。

安装：先在 App 导出备份，再用同包名 APK 覆盖更新，不要卸载或清除数据。

构建：JDK 17、Android API 35 / build-tools 35，minSdk 24、targetSdk 28。
python build_android.py --source . --tools <android-tools目录> --keystore <原签名密钥路径> --build <临时构建目录> --output <输出APK路径>
通过进程环境提供 JINGTING_STORE_PASS；需要时另提供 JINGTING_KEY_PASS。默认 alias 为 jingting-test。
