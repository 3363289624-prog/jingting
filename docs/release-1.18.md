# 精听 1.18-test

安卓包名 `app.jtpractice.offlineplayer`，versionCode **9**。本版继续使用原有签名。升级前建议导出备份，然后覆盖安装同包名 APK；卸载或清除数据会删除本地材料。应用名称仍显示“精听练习·诊断”。

## 本版更新

1. **整份字幕校准**：材料更多操作或播放目录进入，按 0.1 秒提前/延后，范围 ±30 秒。句子切换、跳句、跟读范围和词时间锚点一起平移；支持预览、取消和恢复默认。原有逐词高亮校准可继续单独调整。
2. **收藏连续复习**：顺序或随机播放未掌握的收藏难句，支持标记/取消“已掌握”、跨材料播放及自动下一句。手动拖动进度会退出复习队列。
3. **盲听模式**：播放目录中的二级入口。默认隐藏每句字幕，点击揭晓并可重听；切换句子或重开材料时重新隐藏。
4. **导入配对确认**：导入前预览音频与字幕对应关系，可手动改配或跳过。同名音频默认跳过，明确选择替换后才覆盖；补导字幕同样先确认。批次准备完成后在同一事务中保存。
5. **刷新率和后台播放**：默认跟随系统，可选请求 120Hz。安卓版使用原生播放器、音频焦点、锁屏媒体会话和前台播放服务；耳机断开或音频打断后暂停，不自动恢复。修复快速启停服务超时、旧异步事件影响下一轮跟读及提前释放焦点的问题。

字幕校准、盲听偏好和已掌握状态随材料备份；刷新率设置属于设备设置。请求 120Hz 不保证实际刷新率。

## 验证记录与范围

- 浏览器集成检查 **150/150**，逐词核心检查 **28/28**。
- 一加真机检查 **73/73**：64 项功能检查、8 项原生播放检查，以及原材料元数据和音频大小保持不变检查。
- 检查 320×640、412×892 和 844×390 下的关键界面；通过实际浏览器文件选择器导入 WAV + SRT。
- 检查 APK 的 v2/v3 签名、包名/版本、ZIP CRC、对齐及网页资源一致性。
- 原生播放检查包含 20 次快速启停、短时间锁屏时钟推进、原生/网页定时去重，以及另一测试应用实际抢占音频焦点。

真机自动检查使用合成 WAV。耳机断开检查模拟调用原生接收器路径，未覆盖真实蓝牙设备断连；锁屏检查不是长时间后台耐久测试。耗电对照未执行，**没有省电幅度或续航结论**。句级 SRT 的词时间仍为估算，没有新增语音识别或强制对齐。

网页版继续使用浏览器音频能力，后台可能被系统挂起；原生播放服务、系统音频焦点和刷新率请求属于安卓功能。

音频、字幕和练习状态存放在本机；安卓版临时准备私有音频缓存，不上传音频。不同设备、浏览器、网址和安卓应用之间不会自动共享材料。翻译仅在主动操作时访问用户配置的接口。

源码见 `android/`，构建和测试说明见 `android/README-安卓.txt` 与 `android/tests/README.md`。网页保持单个 `index.html`，没有前端框架、CDN、外部字体或账号系统。签名密钥、密码和测试 APK 不在仓库或源码附件中。
